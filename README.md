# autoclips site

The public pages for the **autoclips** Google OAuth application:

- `index.html` — what the app is
- `privacy.html` — the privacy policy Google requires for a published OAuth app

These are served by GitHub Pages. The repository must be named
`<username>.github.io` for the pages to appear at `https://<username>.github.io/`,
which is the address registered in the Google Cloud console as the application
home page and privacy policy link.

The privacy policy describes what is true of this app: it is a single-user desktop
tool that talks only to the owner's own YouTube channel, stores its credentials
locally, and sends nothing to any third party.
